💰 Expense Tracker

A modern and responsive Personal Expense Tracker that helps users manage their income and expenses, track transactions, and get a quick overview of their financial status.

The application uses Local Storage to securely persist transaction data in the browser, so the data remains available even after refreshing or reopening the website.

✨ Features

* 📊 Financial Summary
    * Total Income
    * Total Expenses
    * Current Balance
      
* ➕ Add Transactions
    * Add income and expense transactions
    * Enter amount, category, date, and description
 
* 📝 Edit Transactions
    * Update existing transaction details whenever required
 
* 🗑️ Delete Transactions
    * Remove unwanted transactions from the history
      
* 🔍 Category Filtering
    * Filter expenses based on categories such as Food, Travel, Shopping, Bills, Education, and more

* 📅 Transaction History
    * View all transactions with date, category, type, amount, and description

* 💾 Local Storage
    * Transaction data is automatically stored in the browser’s Local Storage
    * Data persists even after page refresh

* 📱 Responsive Design
    * Optimized for desktops, tablets, and mobile devices

* 🎨 Modern UI
    * Clean dashboard
    * Responsive layout
    * Smooth interactions
    * User-friendly interface

🚀 How to Run

1. Clone the repository:

2. Open the project folder:

cd expense-tracker

3. Open index.html in your browser.

You can also use VS Code Live Server to run the project locally.

💡 How It Works

1. Add an Income or Expense transaction.
2. Enter the amount, category, date, and description.
3. The transaction is stored in Local Storage.
4. The dashboard automatically updates:
    * Total Income
    * Total Expenses
    * Current Balance
5. Transactions can be edited or deleted at any time.
6. Use the category filter to view specific expenses.

📊 Financial Calculation

The application calculates the financial summary automatically:

Current Balance = Total Income - Total Expenses

For example:

Total Income     = ₹30,000
Total Expenses   = ₹8,500
Current Balance   = ₹21,500

🔐 Data Storage

This project does not require a backend or external database.

All transaction data is stored locally using the browser’s Local Storage API.

Note: Local Storage is browser-specific. Clearing the browser’s site data can remove stored transactions.
